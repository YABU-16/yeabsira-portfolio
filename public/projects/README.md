# Project Screenshots

Drop your real project screenshots in this folder and update the `image` field
in `src/data/portfolio.ts`.

Expected filenames (matching the current data):

- `techgadget.png`
- `hotel.png`
- `marketplace.png`

Until a screenshot exists, each project card automatically shows an elegant
branded placeholder — no broken images. The placeholder disappears as soon as
you add the real file. JPEG/WebP works too; just update the path in the data
file, e.g. `/projects/techgadget.jpg`.

Image tips:
- 16:10-ish aspect ratio looks best on the cards.
- Keep files reasonably small (compress to < 300 KB) for fast loading.
